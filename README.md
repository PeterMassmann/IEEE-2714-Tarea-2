# IEE2714 - Fundamentos de procesamiento de imágenes
## Tarea 2

El presente repositorio contiene el código y los resultados de la Tarea 2 del curso IEE2714 - Fundamentos de procesamiento de imágenes.

El trabajo está dividido en 2 carpetas, una para cada pregunta. Cada carpeta contiene:

* Archivos `.py`: Contienen el grueso de código relacionado a la implementación solicitada.
* Archivos `.ipynb`: Utilizan el código de los archivos `.py` para generar los análisis y resultados solicitados en la tarea.
* Imágenes: Contienen las imágenes utilizadas como referencia para la implementación y el análisis.

### Dependencias

Las dependencias necesarias utilizadas para ejecutar los códigos de la tarea son las siguientes:

* `numpy`
* `matplotlib`
* `scipy` (pregunta 1)
* `Pillow` (pregunta 2)

Adicionalmente, se debe poder ejecutar el código en un entorno que soporte Jupyter Notebook para visualizar los resultados de manera interactiva.
